# Identidade visual

Fonte: BRAND_BOOK_INTERIORES_BARTZ (1).pdf, versão 1.0, outubro de 2026, fornecido pelo cliente.

- Paleta: grafite #2D2D2E, amarelo #F3BC2E, branco #FFFFFF. Evitar branco sobre amarelo.
- Tipografia: Poppins Light nos títulos em caixa alta, tracking 4%; Medium nos destaques, Regular no corpo.
- Padrão: linhas verticais retas, traço de 1/5 do passo, uma linha amarela a cada 6–9 linhas; separado do logotipo.
- `logo-horizontal.svg`: recorte vetorial da versão horizontal de destaque da página 5, preservando o desenho original. O nome Bartz no logo não foi recomposto para acompanhar o nome do produto Bart Studio.
- Poppins obtida do repositório oficial google/fonts; licença OFL distribuída em ../fonts/OFL.txt. Arquivos locais evitam dependência do Google Fonts em runtime.
- A ilustração de interiores representa materiais, não amplia a paleta institucional.

O PDF é referência de identidade; contatos e textos de exemplo do manual não foram publicados como dados reais da empresa.

- `logo-horizontal-positivo.svg`: versão positiva original do mesmo brand book, extraída em vetores grafite, com fundo transparente, para a abertura clara.
